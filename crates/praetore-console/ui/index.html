Bandeja

Cada solicitud muestra sus parámetros: la firma los cubre. El primer clic muestra el resumen y el segundo firma una sola decisión. «Aprobar y ejecutar» registra la aprobación y pide la única ejecución; si la ejecución no se puede hacer, la solicitud queda aprobada, pendiente de ejecución, y solo se reintenta la ejecución. Rechazar es final. La firma la hace esta consola en este computador; el registro y la ejecución los hace el sistema.

    Paquete de compliance

    Descarga un archivo comprimido (.tar.gz) para entregar a un auditor. Trae el registro firmado que lee esta consola, la política configurada y su digest, las claves públicas del atestador, las sumas SHA-256 de cada archivo y un LEEME.txt que explica cómo verificarlo con praetore-verify sin confiar en esta consola, y lo que el paquete no prueba. Si la consola tiene configuradas claves de ejecución o de aprobador, trae también approvals.jsonl, con los recibos de aprobación, rechazo, vencimiento y ejecución de cada solicitud retenida, y las claves públicas de ejecución y de aprobador que los verifican. Incluye la salida de cada acción ejecutada, que puede tener datos sensibles: revísela antes de entregar el paquete. No trae claves privadas. Descargarlo no cambia nada.
