# Security Policy

PRÆTORE is security-sensitive infrastructure.

Security vulnerabilities should not be disclosed through public issues.

Please report suspected vulnerabilities privately to PRÆTOR TECHNOLOGIES.

Do not include credentials, private keys, personal data, or other sensitive
information in public repository issues or pull requests.

Security reports will be evaluated according to severity, exploitability,
impact, and affected trust boundaries.

## Concerns about the use of AI

PRÆTORE is used to govern AI-enabled systems. A concern about the use of AI
does not have to be a vulnerability. For example:

- a statement in this project that overstates what PRÆTORE does or shows;
- PRÆTORE or its evidence being used to misrepresent how a decision was made;
- harm, or a risk of harm, from an AI-enabled system that uses PRÆTORE;
- the use of AI in developing this project.

To report one privately, use
[GitHub private reporting](https://github.com/Mavericksantander/praetore/security/advisories/new)
and start the title with `AI use concern:`. Only you and the maintainers can
see the report. You need a GitHub account, and you do not need proof or a technical
finding. Please include what you saw and where, and leave out personal data
that the report does not need. If the concern involves no sensitive
information, you can also open a public issue.

Reports are read by the maintainers, who may ask for more detail. This channel
is not an emergency service: if there is an immediate risk to someone, contact
the operator of the system or the competent authorities first.

See [Limitations and responsible use](docs/limitations-and-responsible-use.md).
